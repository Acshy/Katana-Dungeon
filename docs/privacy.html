Katana&Dungeon 隐私政策

生效日期：2026-11-25　版本：1

开发者：Acshy；联系渠道：GitHub 仓库 Issues。

我们处理的信息

游戏在本地生成并保存一个随机玩家标识，供 TapTap 实名与防沉迷服务使用；清除应用数据、重装或更换设备后，该标识会重新生成。该标识及完成实名认证、防沉迷校验所需的信息，会在玩家同意后发送给 TapTap。游戏使用 TapADN SDK 展示广告，SDK 可选信息采集范围应以本应用实际设置和玩家同意为准。

第三方 SDK

游戏使用 TapTap SDK（仅用于实名认证与防沉迷）和 TapADN SDK（广告）。游戏不调用 TapTap 登录、云存档或 TapDB 事件统计功能。第三方 SDK 的准确信息类型、处理方式与保存期限，发布前须对照其当前隐私政策和本应用实际配置核实。

信息用途和保存

本地玩家标识用于识别本机的防沉迷校验记录；TapTap 与 TapADN 按各自服务目的处理其收到的信息。游戏进度保存在本地。具体保存期限及第三方 SDK 的保存规则，需由开发者核实后补充。

你的权利

你可以通过 GitHub 仓库 Issues 咨询个人信息处理事项，也可以撤回隐私同意。撤回同意后，实名认证、防沉迷或广告服务可能不可用，游戏将无法继续进入。

未成年人保护

游戏通过 TapTap 实名与防沉迷服务执行未成年人保护要求。未完成实名认证或不符合进入条件时，游戏不会允许进入。

更新与联系

政策更新后会在本页面公布版本和生效日期。问题请通过 GitHub 仓库 Issues 联系开发者。

Katana&Dungeon 用户协议

生效日期：2026-11-25　版本：1

接受协议

开始使用游戏即表示你已阅读并同意本协议和隐私政策。不同意时请退出游戏。

游戏服务

开发者提供游戏客户端、TapTap 实名与防沉迷校验、TapADN 广告服务及页面中列明的其他功能。服务可能因维护、网络或第三方平台原因暂时不可用。

账号与合规

请遵守 TapTap 平台规则及相关法律法规。未通过实名认证与防沉迷验证时，游戏将限制进入。

禁止行为

不得利用漏洞、外挂、脚本或其他方式破坏游戏公平性、干扰服务、侵犯他人权益或违反法律法规。

内容与更新

开发者可以修复问题、调整内容或更新客户端。重大变化会在本页面或游戏内提示。

联系

关于本协议的问题请通过 GitHub 仓库 Issues 联系开发者。
